# Device configurations

The original simulator project and complete running configurations were not available for this documentation bundle. The Arabic report includes selected configuration excerpts that were supplied by the project owner, with CHAP secrets removed from the public copy.

Do not treat normalized `Manager` / `Employee` VLAN-name lines in the report as a newly captured running configuration. They express the documented role mapping and should be compared with `show vlan brief` if the original simulator file becomes available.

Before publishing any additional config files:

- Remove shared secrets, passwords, keys, tokens, and personal information.
- Label partial/normalized snippets as examples, not complete running configs.
- Identify the router/switch and interface represented by each file.
- Avoid committing platform state files containing credentials or local paths.
